# Test-Skills

1. Lee la skill a probar y entiende qué debe hacer.
2. Crea 3 casos de prueba: uno normal, uno límite y uno con entrada incorrecta.
3. Ejecuta cada caso siguiendo la skill al pie de la letra.
4. Compara el resultado con lo esperado.
5. Reporta en una tabla: caso, resultado esperado, resultado real, pasa/falla.
6. Si hay fallos, propone una corrección concreta de la skill.

Reglas:
- No modifiques la skill sin que se pida; solo reporta y sugiere.
- Prueba una skill a la vez.
