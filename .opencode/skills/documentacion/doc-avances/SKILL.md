# Doc-Avances

1. Abre el documento de avances (ej. `AVANCES.md`). Si no existe, créalo.
2. Agrega una entrada con este formato:
   - **Fecha:**
   - **Qué se hizo:**
   - **Estado:** (completado / en curso / bloqueado)
   - **Pendiente / siguiente paso:**
3. Mantén las entradas en orden cronológico, la más reciente arriba.
4. Actualiza el estado de entradas anteriores si cambiaron.

Reglas:
- Solo toca la documentación de avances, no el código ni otros archivos.
- Sé breve: máximo 3 líneas por entrada.
- Registra solo hechos, sin suposiciones.
